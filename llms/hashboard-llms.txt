# Hashboard

> Hashboard is a business intelligence (BI) platform built around a BI-as-code workflow: data teams define their semantic layer, metrics, explorations, and dashboards as version-controlled configuration files and manage them with the Hashboard CLI (hb) and the hashquery Python framework. Changes are previewed, code-reviewed, and deployed through CI/CD. The hosted app delivers interactive dashboards and metric pages on top of the customer's own cloud data warehouse (query-based, no full data ingestion). Hashboard is SOC 2 Type II certified and supports HIPAA/BAAs. (Acquired by Hex Technologies.)

## Developer tools
- [hashboard-cli on PyPI](https://pypi.org/project/hashboard-cli/): `pip install hashboard-cli` (binary `hb`).
- [hashquery on PyPI](https://pypi.org/project/hashquery/): `pip install hashquery` (Python BI framework).
- [hashquery on GitHub](https://github.com/hashboard-hq/hashquery): Source for the Python framework.
